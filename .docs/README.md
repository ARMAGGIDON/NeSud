# Документація NeSud

Це документація фактичного проєкту, а не вимоги до майбутньої реалізації. Редагувати разом зі змінами коду.

| Файл | Зміст |
|---|---|
| [PROJECT.md](PROJECT.md) | Функціональність, правила, економіка, акаунти, SMTP, конфігурація, запуск |
| [ARCHITECTURE.md](ARCHITECTURE.md) | Компоненти, карта коду, схема БД, мережа та інваріанти |
| [UI-UX.md](UI-UX.md) | Композиція, навігація, принципи представлення даних та аудит |
| [VERIFICATION.md](VERIFICATION.md) | Команди, докази, ручне приймання, залишкові обмеження |

Не зберігати реальні паролі, email, токени, ключі запрошень, файли БД або приватні журнали в документації. У разі розбіжності з реалізацією перевірити вихідний код і актуалізувати документ.
