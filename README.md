# NeSud

Нативний настільний застосунок судоку для Windows на C# / WPF / .NET 10. Не потребує підключення до мережі чи зовнішньої БД.

## Запуск

Потрібен .NET 10 SDK і Windows 10/11.

```powershell
dotnet run --project src/NeSud
```

Для IDE відкрийте `NeSud.slnx`.

## Можливості

- Генерація полів 9×9 із перевіркою єдиного розв’язку та чотирма рівнями складності.
- Асинхронна генерація з можливістю скасування; попередня гра зберігається до успішної генерації нової.
- Світла/темна тема, адаптивне квадратне поле, виділення клітинки, рядка, стовпця, блока й однакових цифр.
- Нотатки, автоматичні кандидати, очищення нотаток сусідів, підказки з назвою техніки або явним відкриттям відповіді.
- Скасування/повторення (до 150 ходів), пауза з прихованим полем, перезапуск, таймер, помилки, прогрес, статистика.
- Автоматичне збереження стану після дій і кожні п’ять секунд активної гри; резервна копія, відновлення після перезапуску.
- Збереження поточної головоломки, ходів, нотаток, історії, часу, підказок, помилок, вибраної клітинки, теми, налаштувань і розмірів вікна.
- Рекорд часу враховує лише завершення без помилок і підказок; одна головоломка зараховується один раз.

## Керування

| Клавіша | Дія |
| --- | --- |
| Стрілки | Вибрати клітинку |
| 1–9 / NumPad | Ввести цифру |
| Shift+цифра | Додати або прибрати нотатку |
| N / Space на полі | Режим нотаток |
| Delete / Backspace / 0 | Очистити клітинку |
| Ctrl+Z | Скасувати |
| Ctrl+Y / Ctrl+Shift+Z | Повторити |
| H | Підказка |
| A | Заповнити кандидатів |
| P / Esc | Пауза / продовжити; Esc також скасовує генерацію |
| Ctrl+N | Нова головоломка |
| F1 | Довідка |
| Tab / Enter | Навігація й активація кнопок |

## Складність

| Рівень | Задані цифри | Умова |
| --- | ---: | --- |
| Легка | 42–46 | Розв’язується простими або прихованими одинаками |
| Середня | 34–38 | Розв’язується простими або прихованими одинаками |
| Складна | 28–32 | Єдиний розв’язок, менше початкових цифр |
| Експерт | 24–27 | Одинаків недостатньо для повного розв’язання |

Це евристична класифікація, а не повний рейтинг людських логічних технік. Генератор видаляє цифри з випадково створеного правильного поля, перевіряючи кількість розв’язків пошуком із MRV. Усі рівні мають рівно один розв’язок. Помилки та використані підказки не скидаються через Undo, щоб зберігалася статистика спроб.

## Збереження

`%LOCALAPPDATA%\NeSud\state.json`, резервна копія `state.json.bak`. Запис через тимчасовий файл із заміною. Одночасний запуск двох екземплярів у межах однієї сесії блокується.

## Перевірка

```powershell
dotnet build NeSud.slnx
dotnet run --project tests/NeSud.SmokeTests -c Release -- 3
```

Параметр `3` задає кількість генерацій для кожної складності. Smoke-тести не потребують сторонніх пакетів. Для перевірки UX запустіть застосунок на Windows: змініть тему, введіть цифри й нотатки, перевірте Undo/Redo, паузу, перезапуск і відновлення після закриття.

## Публікація

```powershell
dotnet publish src/NeSud -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

Результат: `src/NeSud/bin/Release/net10.0-windows/win-x64/publish/`.
